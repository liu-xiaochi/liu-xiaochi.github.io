# 刘小驰的个人学术主页

纯静态网页，无需安装依赖。修改 profile.js 可更新姓名、单位简介、邮箱及 GitHub 地址。

## 本地预览

在此目录运行 `python -m http.server 8765 --bind 127.0.0.1`，浏览器访问 http://127.0.0.1:8765。

## GitHub Pages

将 index.html、style.css、profile.js、script.js 和 .nojekyll 上传到公开仓库的 main 分支。在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。

若仓库名是 GitHub用户名.github.io，网址为 https://GitHub用户名.github.io/；普通仓库的网址为 https://GitHub用户名.github.io/仓库名/。

站点不包含未经提供的论文、研究方向或履历。
