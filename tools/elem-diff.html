ElemDiff Web 0.1

这是一个单文件、离线可用的元素扩散计算器。它把 Python 版 ElemDiff 的核心功能移植到浏览器：不需要安装 Python，不需要服务器，双击 HTML 就能运行。所有计算都在本机浏览器内完成，数据不会上传。

三个工作页

  • 正演：一维球/柱/平面有限体积扩散，支持 D(T,C)、恒温/线性冷却/1/T 冷却、固定浓度或零通量边界，以及晶体-熔体双层界面（Kd）。
  • 反演：从实测阶梯/台地剖面拟合 Dt 和初始几何，给出 R²、RMSE、约化 χ² 与 1σ 误差；可换算扩散时间。
  • 封闭温度：Dodson (1973) 公式，球/柱/平面三种几何因子。

控制方程

∂C/∂t = (1/r^γ) ∂/∂r [ r^γ D ∂C/∂r ]，γ = 0（平面）/ 1（圆柱）/ 2（球体）

离散采用单元中心有限体积，界面传导率 G = A / (Δr_L/(2D_L) + Δr_R/(2D_R))；时间推进为 Backward Euler，非线性 D(C) 用 Picard 迭代，步长由剖面相对变化自适应控制。

双层界面

C晶体 = Kd · C熔体，D_c ∂C_c/∂r = D_m ∂C_m/∂r

消去界面浓度后得到等效传导率 G_int = a c / (a + c/Kd)，其中 a = D_c A/δ_c，c = D_m A/δ_m。这样界面两侧浓度成 Kd 比例、通量连续，闭边界下总质量守恒。

反演公式

阶梯：C = C_L + (C_R−C_L)/2 · erfc((x−x0)/(2√Dt))
台地：C = C_out + (C_in−C_out)/2 · [erf((x−x1)/(2√Dt)) − erf((x−x2)/(2√Dt))]

用 Nelder–Mead 多初值最小二乘拟合，误差由数值 Jacobian 的线性化协方差估计。反演使用无限介质解析解；当扩散长度接近颗粒半径时，应回到正演页用数值模型核对。

封闭温度

Tc = Ea / [ R · ln( A · R · Tc² · D0 / (Ea · a² · |dT/dt|) ) ]

A 为几何因子：球 55、圆柱 27、平面 9.5。公式对 Tc 隐式，程序用阻尼不动点迭代，失败时在 50–5000 K 内扫描二分。

单位

长度 µm；时间 ka；D0 m²/s；Ea kJ/mol；温度 °C；浓度任意一致单位。内部换算为 m、s、K、J/mol。

与文件夹资料的关系

  • DIFF-CL（Ganguly & Tirone, 1999）：封闭温度、冷却年龄、几何因子。
  • Hesse (2012) 有限体积程序：球/柱/平面离散、晶体-熔体界面、质量守恒。
  • Diffuser（吴黎光, 2022）、Lubbers notebook：阶梯/台地剖面与 Dt 拟合。
  • DFENS（Mutch et al.）：扩散计时与参数不确定性的思路。
  • Dodson (1973)：Tc 公式与 A = 55/27/9.5。

局限

  • 一维对称几何，颗粒内温度均匀；双层界面固定，不模拟晶体生长/溶解。
  • D 只依赖 T 和局部浓度，不含压力、fO₂、各向异性、多组分耦合。
  • 反演用无限介质解析解；误差为线性化 1σ，不是完整后验。
  • 暂不支持 Excel 直接读取（可另存为 CSV），也不支持 2D/3D。

验证

Python 版与浏览器版使用同一套方程和步长策略。已对照 Crank 解析解检查半空间/球体剖面，检查闭边界质量守恒、双层界面平衡、Dt 反演恢复和 Dodson Tc。Python 测试：python -m unittest discover -s tests -v（9 项通过）。
