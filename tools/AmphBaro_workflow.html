AmphBaro 使用流程

角闪石压力计 · 从 EMPA 成分到压力综合 · Amphibole Barometry Workflow

v1.1 8 种标定 离线单文件
返回 AmphBaro

目的

从角闪石电子探针成分出发，重算结构式，判断成分/温压范围，比较 8 种 Al-in-hornblende 压力标定，给出首选压力、跨方法范围与可追溯的输出。

使用前提

钙质角闪石（CaB ≥ 1.5）；与 Qtz + Pl + Kfs + Bt + 钛铁氧化物 + 熔体 共生；矿物平衡、未蚀变；成分在标定范围内。程序不判断平衡。

输入参数

11 种氧化物 wt.%（SiO₂…K₂O）；FeO(T) 全铁或 FeO + Fe₂O₃ 分别给出；可选 T；Fe³⁺ 方案；压力单位 kbar / MPa。

操作流程

从左到右、从上到下
1

输入 EMPA 成分 Input

从 Excel 粘贴或手动编辑；先确认样品名与数据来源。

SiO₂TiO₂Al₂O₃Cr₂O₃FeO(T)Fe₂O₃MnOMgOCaONa₂OK₂O
2

检查数据与前提 Check

氧化物总量 95–101 wt.%；关键氧化物非空；角闪石为钙质；共生组合满足。示例数据需替换。

CaB ≥ 1.5 且数据完整？
是 → 进入重算
否 → 非钙质/缺数据：停止或仅作参考
3

重算结构式 Recalculate

23 O 归一化；Leake (1997) 13/15-CNK；Fe³⁺ 由电荷平衡（或全部 Fe²⁺、固定 Fe³⁺/ΣFe、输入 Fe₂O₃）；分配 T / C / B / A 位。

Al_totAl_IVAl_VICa_BNa_BNa_AK_AMg#Fe³⁺
4

按方法切换基准 Basis

同一份成分，不同标定使用不同重算基准。

Ridolfi 201013-CNK → Al_tot
Si* → T
Xu 202115-CNK → Al_VI
Mutch / 经典23 O → Al_tot
5

代入 8 种压力方程 Equations

使用右侧方程区；P 统一换算为 kbar（MPa / 100）；Ridolfi T 由 Si* 计算。

6

压力综合 Synthesis

选择首选方法；同时查看跨方法范围、中位数与方法家族范围。跨方法范围不是分析不确定度。

跨方法极差 > 2 kbar？
否 → 方法间较一致
是 → 方法间不一致：检查标定/组合
7

输出与解释 Output

首选 P、跨方法范围、T、结构式；导出 CSV / 项目 JSON / 打印。状态“范围内”只指成分/温压范围，不判断矿物平衡。

8 种压力方程

P 统一显示为 kbar；MPa / 100

Ridolfi et al. (2010)

13-CNK
P(MPa) = 19.209 · exp(1.438 · Al_tot)
T(°C) = 2041 − 151.487 · Si*
P/100 = kbar；T ±22 °C；约 1–8 kbar。

Mutch et al. (2016)

23 O
P(kbar) = 0.5 + 0.331 · Al_tot + 0.995 · Al_tot²
对高铝角闪石更敏感。

Xu et al. (2021)

15-CNK
P(kbar) = 16.75 · Al_VI − 0.48
Al_VI 为 C 位 Al。

Schmidt (1992)

23 O
P(kbar) = 4.76 · Al_tot − 3.01
约 2–13 kbar；700–1000 °C。

Johnson & Rutherford (1989)

23 O
P(kbar) = 4.23 · Al_tot − 3.46
约 1–8 kbar。

Hammarstrom & Zen (1986)

23 O
P(kbar) = 5.03 · Al_tot − 3.92
约 1–8 kbar。

Hollister et al. (1987)

23 O
P(kbar) = 5.03 · Al_tot − 3.53
约 1–8 kbar。

Anderson & Smith (1995)

23 O + T
P = −3.01 + 4.76·Al_tot − [(T−675)/85] · [0.53·Al_tot + 0.005294·(T−675)]
±0.6 kbar；T 675–1000 °C；负值 → 不适用。
