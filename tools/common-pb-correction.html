三种方法

      

        
方法适用对象前提

        
207Pb 法普通 Pb 较低的锆石、独居石（f206 < 20%）样品谐和；普通 Pb 组成已知

        
总 Pb 迭代法普通 Pb 很高（30–90%）的独居石有 208Pb/232Th 与 Th、U；以 208/232 年龄为锚

        
T-W 截距法同一岩浆事件的样品群同组同时代、普通 Pb 组成一致

      


      
207Pb 法（对应 09FW132 年龄.xls）

      

r76_rad(t) = (e^(λ235·t) − 1) / [137.818·(e^(λ238·t) − 1)]
f206       = (r76_meas − r76_rad) / (r76_common − r76_rad)
(206/238)corr = (206/238)meas · (1 − f206)
      

      
以测得的 206Pb/238U 年龄为起点，反算理论放射成因 207Pb/206Pb；实测多出来的部分就是普通 Pb。扣除后重算年龄，迭代到稳定。


      
总 Pb 三维迭代法（对应 Mottram 表与 docx）

      

Δ(207/235)   = (207/235)meas − (e^(λ235·t) − 1)
(206/238)com = Δ / (137.818 · r76_common)
(208/232)com = r86_common · (206/238)com · (238U/232Th)原子
      

      
以 208Pb/232Th 年龄（对普通 Pb 最不敏感）为锚，求普通 206Pb，再用 Th/U 求普通 208Pb，迭代到 207/235 与 208/232 年龄一致。


      
Tera-Wasserburg 截距法

      
在 238U/206Pb—207Pb/206Pb 图上，作通过普通 Pb 组成点 (0, 207/206c) 的加权回归，与谐和线的下交点即年龄。按样品分组分别回归。


      
普通 Pb 组成

      
Stacey-Kramers (1975) 两阶段：4.57–3.70 Ga（μ=7.19，Th/U=4.62），3.70 Ga–现在（μ=9.74，Th/U=3.78），现今 18.700 / 15.628 / 38.630。注意 207 的演化使用 235U/204Pb = μ/137.818。

      
“样品年龄时的组成”比“现今组成”严格；0.42 Ga 时 207/206 会从 0.8356 变到 0.8643，对老样品不可忽略。


      
误差

      
所有年龄误差为 2σ。程序对 206Pb/238U 与 207Pb/235U 的对数误差按 Rho 联合抽样，每个 Monte-Carlo 试验完整走一遍迭代，取 1σ 标准差 × 2。Rho 定义与 Isoplot 相同：

      
ρ = (σ68² + σ75² − σ76²) / (2·σ68·σ75)


      
判据

      
    
        
  • f206 < 20%：207 法可靠；
    • 
        
  • 20–50%：207 法对普通 Pb 组成假设敏感，结果仅供参考；
    • 
        
  • > 50%：建议改用总 Pb 迭代法或 T-W 截距法；
    • 
        
  • > 100% 或 < 0：数据不自洽，自动标记“剔除”。
    • 
      


      
输入格式

      
表头需出现在前 12 行内，至少含 206Pb/238U 与 207Pb/235U（或 207Pb/206Pb）。也接受 238U/206Pb（自动取倒数）、208Pb/232Th Age (Ma)（自动反算比值）。误差列支持 2s%p、2s%、1sigma、2s ab 等写法。

      
普通 Pb 组成的不确定度属于系统误差，未计入 2σ；f206 越高，结果对它越敏感。
